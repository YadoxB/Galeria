Sortir la comparaison des Réglages

Aujourd'hui, comparer les fiches avec le site se trouve dans Réglages → Site web → « Comparer les fiches avec le site… ». C'est un écran de travail quotidien rangé dans un tiroir de configuration : trois clics, et il faut savoir qu'il existe (Dave, 2026-09-08 : « ces fonctions sont loin dans les réglages et ce n'est pas évident à trouver »).

Le changement : une entrée de menu

Le menu latéral gagne Site web, juste au-dessus d'Outils, dans le bloc du bas avec les utilitaires. Un clic au lieu de trois, et surtout : on le voit sans le chercher. Réglages ne garde que ce qui y appartient vraiment — l'adresse du site et les clés d'accès.

Aujourd'hui

Rien n'annonce que l'app sait parler au site. La fonction vit dans Réglages, entre les clés d'accès et les sauvegardes.

Proposé

Une entrée Site web dans le bloc des utilitaires. À côté d'Outils : c'est un système périphérique, pas une section du catalogue.

Site web

L'app lit la boutique et vous propose de reprendre des valeurs. Rien n'est jamais modifié sur le site.

Ce que Réglages garde

Uniquement la connexion : l'adresse du site, les clés, le bouton pour tester. Le gros bouton « Comparer les fiches avec le site… » cède la place à un simple renvoi — celui qui l'a appris ne se retrouve pas devant un vide.

Site web

Relier l'application à la boutique du site.

La comparaison des fiches se fait maintenant depuis Site web, dans le menu de gauche.

Connexion au site (adresse et clés)

Adresse, clé, secret, bouton « Tester la connexion » — inchangés.

Les points qui méritent un mot

  • Un état de connexion visible. Depuis les Réglages, un garde-fou vérifiait les clés avant d'ouvrir l'écran. Avec une entrée de menu, on y arrive directement : l'écran doit donc dire lui-même s'il est relié, et mener aux Réglages si non — au lieu de laisser cliquer « Comparer » pour n'obtenir qu'un message d'erreur.
  • Les deux onglets restent. Œuvres et Artistes ne deviennent pas deux entrées de menu : c'est la même tâche vue sous deux angles, et deux entrées voisines auraient obligé à choisir avant de savoir.
  • Les actions groupées ne bougent pas — « Importer les textes anglais », « Récupérer les adresses », « Séparer les citations » restent où elles sont, en tête de leur onglet.
  • Les boutons « Comparer avec le site » des fiches d'artiste et d'œuvre ne changent pas non plus. Ils servent à autre chose : vérifier une fiche qu'on a sous les yeux.
