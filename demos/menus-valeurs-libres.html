⚠ Une conséquence à connaître avant d'ouvrir le champ « Type » d'une œuvre

Le type choisit le texte d'attestation du certificat d'authenticité, par correspondance partielle : sculpt → sculpteur, reprod → reproduction, photo → photographe, estamp/gravu → graveur, dessin → dessinateur. Tout le reste retombe silencieusement sur « peintre ».

Un type inédit comme « Céramique » ou « Installation » produirait donc un certificat attestant une « production authentique de l'artiste peintre ». Le type gouverne aussi la commission : sculpt donne 33 %, tout le reste la cote par défaut.

À noter : ce risque existe déjà — le champ accepte du texte libre aujourd'hui. Le rendre visible le rend simplement plus probable. Si vous le souhaitez, j'ajoute un avertissement au moment de produire un certificat pour une œuvre dont le type n'est pas reconnu, plutôt que de laisser le repli passer sous silence.
