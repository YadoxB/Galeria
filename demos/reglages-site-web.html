Connexion à la boutique

✓ Clés définies · chiffrées dans le coffre Windows

La clé et le secret sont chiffrés dans le coffre de Windows (jamais affichés ni stockés en clair). Le test se contente de lire la boutique — il ne peut rien modifier sur le site. Tu peux révoquer ces clés à tout moment depuis le site, sans effet sur son contenu.

Pour créer les clés sur le site : WooCommerce → Réglages → Avancé → API REST → Ajouter une clé. Une permission Lecture suffit pour comparer ; la Lecture/écriture ne sera utile que plus tard, pour mettre le site à jour depuis l'app (toujours avec confirmation).
