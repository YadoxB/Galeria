Relier Galeria à votre site web

Comment obtenir la « clé d'accès » du site — à faire une seule fois

Galeria peut comparer vos fiches (œuvres et artistes) avec la boutique de votre site et vous aider à les tenir à jour. Pour cela, le site doit lui donner une clé d'accès en lecture. C'est sans danger : cette clé permet seulement de lire le site — Galeria ne peut rien modifier en ligne. La marche à suivre prend environ 5 minutes.

Les étapes, une à une

1

Ouvrir l'administration du site

Dans un navigateur (Chrome, Edge…), allez à l'adresse :

galerievieuxstjean.com/wp-admin

Connectez-vous avec l'identifiant et le mot de passe du site (ceux de WordPress).

2

Aller dans les réglages de la boutique

Dans le menu de gauche, cliquez sur WooCommerce, puis sur Réglages (Settings).

3

Ouvrir « API REST »

En haut de la page, cliquez sur l'onglet Avancé (Advanced), puis sur API REST (REST API).

4

Créer la clé

Cliquez sur Ajouter une clé (Add key / Create an API key), puis remplissez :

  • Description : écrivez Galeria (pour la reconnaître plus tard).
  • Utilisateur : choisissez votre compte.
  • Permissions : choisissez « Lecture » (Read). C'est le plus sûr — Galeria n'a besoin que de lire.

Cliquez ensuite sur Générer une clé d'API (Generate API key).

5

Copier les deux codes

Le site affiche alors deux codes :

  • une Clé du client (Consumer key) — commence par ck_…
  • un Secret du client (Consumer secret) — commence par cs_…
Important : ces deux codes ne s'affichent qu'une seule fois. Copiez-les tout de suite (bouton « Copier »), ou notez-les soigneusement, avant de fermer la page.
6

Les entrer dans Galeria

Ouvrez Galeria, puis allez dans Réglages → Site web.

  • Dépliez « Connexion au site ».
  • Adresse du site : https://galerievieuxstjean.com
  • Collez la Clé (ck_…) et le Secret (cs_…).
  • Cliquez sur Enregistrer, puis sur Tester la connexion.

Si le message « Connexion réussie » apparaît : c'est terminé ! 🎉

Quelques précisions rassurantes

  • Aucun risque pour le site. La clé est en lecture seule : Galeria ne peut rien changer ni supprimer en ligne.
  • Vos codes sont protégés. Une fois entrés dans Galeria, ils sont rangés de façon chiffrée sur l'ordinateur — jamais affichés en clair.
  • En cas de doute ou d'erreur. Vous pouvez toujours retourner sur le site (étape 3), supprimer la clé nommée « Galeria » et en refaire une nouvelle. Rien n'est cassé.
